# 项目材料

| 子目录 | 内容 |
|---|---|
| reports | 原稿、原始提交、省赛修改、国赛提交的报告和演示材料 |
| figures | 不同阶段的插图、矢量源文件及绘图工程 |
| videos | 演示及相关视频 |
| registration | 报名文件和证明材料，仅保留在本地，不纳入 Git |
| report-tools | 历史报告修改和图片生成辅助脚本及素材 |

不同内容的版本均保留；完全相同的文件只存一份，多个源位置由迁移清单指向同一目标。未根据文件名“最新版”或修改时间自动丢弃报告。

report-tools 为历史辅助代码，可能依赖原桌面路径，不属于应用运行入口，本轮不改写或执行这些脚本。
